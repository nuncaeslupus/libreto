A writing tool for interactive stories: scripts, puzzles, timelines and branching narratives, designed to work hand in hand with an AI assistant.

Born to write [Alter Ego](https://github.com/nuncaeslupus), a pixel-art graphic adventure, but meant to be useful for any writer of games, novels or screenplays.

**Status:** requirements gathering. No code yet.

## Goals (draft)

- Puzzle dependency graphs and timelines linked to the scenes that tell them.
- Track what each character, and the player, knows at every point.
- Cards, colors and research material (notes, images, links).
- Plain, portable project files that work with git and with AI agents.
- Export to formats a game engine can consume.
- Linux first, then Windows and macOS.
